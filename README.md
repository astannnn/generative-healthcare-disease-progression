# AI and Generative Models in Health and Disease Progression

This repository contains the implementation of my bachelor thesis project focused on the application of artificial intelligence and generative models in healthcare.

The main objective of this study is to evaluate whether synthetic healthcare data generated by a Variational Autoencoder (VAE) can be effectively used for healthcare prediction tasks in the context of disease progression research. Alzheimer’s disease is used as a case study with a publicly available tabular clinical dataset.

## Project Overview

Healthcare datasets are often limited because of privacy restrictions, high data collection costs, and difficulties in data sharing. One possible solution is the use of generative models to create synthetic data that preserves useful statistical patterns of real patient data.

In this project, baseline machine learning models are first trained on real clinical data. Then, a VAE is implemented to generate synthetic patient records. After that, the same models are trained on synthetic data, and their performance is compared with the results obtained from real data.

## Research Goal

The goal of this project is to investigate whether synthetic data can serve as a useful supportive resource for healthcare prediction tasks, especially in situations where real healthcare data is limited or sensitive.

## Methods Used

### Baseline Models
- Logistic Regression
- Random Forest
- Neural Network

### Generative Model
- Variational Autoencoder (VAE)

## Workflow

The project follows these main steps:

1. Dataset loading  
2. Data preprocessing and cleaning  
3. Feature normalization  
4. Train-test split  
5. Baseline model training on real data  
6. VAE design and training  
7. Synthetic data generation  
8. Baseline model training on synthetic data  
9. Performance comparison between real-data-trained and synthetic-data-trained models  

## Files in This Repository

- `alzheimers_synthetic_data_prediction.ipynb` — main notebook containing preprocessing, modeling, synthetic data generation, and evaluation  
- `alzheimers_disease_data.csv` — dataset used in the project  
- `requirements.txt` — required Python libraries  

## Evaluation Metrics

The models are compared using:
- Accuracy  
- Precision  
- Recall  
- F1 Score  
- Confusion Matrix
