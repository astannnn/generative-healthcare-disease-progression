# Generative Modeling for Alzheimer’s Disease Progression Prediction Using Tabular Clinical Data

This repository contains the implementation of my bachelor thesis project focused on the use of artificial intelligence and generative modeling for Alzheimer’s disease prediction using tabular clinical data.

The main objective of this study is to evaluate whether synthetic clinical data generated by a Conditional Variational Autoencoder (CVAE) can preserve enough predictive information to train machine learning models for Alzheimer’s disease classification.

The project uses a publicly available cross-sectional tabular dataset containing demographic, clinical, behavioral, and cognitive patient variables.

## Project Overview

Healthcare datasets are often limited because of privacy restrictions, high data collection costs, and difficulties in data sharing. One possible approach to addressing these limitations is the use of generative models to create synthetic data that preserves useful statistical patterns from real patient records.

In this project, baseline machine learning models are first trained on real clinical data. Then, a Conditional Variational Autoencoder is implemented to generate synthetic patient records for each diagnostic class. After that, the same baseline models are trained on synthetic data, and their performance is compared with the results obtained from real data.

The available dataset is cross-sectional and contains a binary `Diagnosis` target. Therefore, the experimental task is defined as Alzheimer’s disease diagnostic status classification rather than direct longitudinal prediction of patient progression over time.

## Research Goal

The goal of this project is to investigate whether synthetic tabular clinical data can serve as a useful complementary resource for Alzheimer’s disease prediction, especially in situations where access to real healthcare data is limited or sensitive.

## Methods Used

### Baseline Models

- Logistic Regression
- Random Forest
- Neural Network

### Generative Model

- Conditional Variational Autoencoder (CVAE)

## Workflow

The project follows these main steps:

1. Dataset loading
2. Data preprocessing and cleaning
3. Feature and target separation
4. Train-test split
5. Feature normalization
6. Baseline model training on real data
7. CVAE design and training
8. Class-specific synthetic data generation
9. Baseline model training on synthetic data
10. Performance comparison between real-data-trained and synthetic-data-trained models

## Files in This Repository

- `alzheimers_synthetic_data_prediction.ipynb` — main notebook containing preprocessing, model training, synthetic data generation, and evaluation
- `alzheimers_disease_data.csv` — dataset used in the project
- `requirements.txt` — required Python libraries

## Evaluation Metrics

The models are compared using:

- Accuracy
- Precision
- Recall
- F1-score
- Confusion matrix
